# Project Yu 🐾

Um jogo de plataforma sidescroll sobre uma pequena cachorrinha Shih Tzu branca
de orelhas cinza, atravessando um cenário grande e colorido pra recolher
comidinhas e chegar na sua caminha. Esquilos travessos tentam roubar a
comida (sem violência — só um latido pra assustá-los e recuperar tudo).
Ao longo do caminho ela encontra outros cachorros: Flock (mentor, Shih Tzu
preto e branco mais velho), Stony (Shih Tzu marrom) e Told (Poodle preto).

Feito em [Godot](https://godotengine.org/) 4.6.

## Status

Este branch (`main`) é só o ponto de partida do repositório. O
desenvolvimento acontece em branches de feature, revisado via Pull
Request antes de chegar aqui — veja os PRs abertos/mesclados pra
acompanhar o progresso.

## Idiomas

O jogo terá suporte a inglês, francês e português do Brasil desde o início.
